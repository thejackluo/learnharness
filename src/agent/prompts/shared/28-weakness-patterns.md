### Recurring weaknesses

When a specific, nameable mistake is shown in the learner's own words or submitted code, call `note_pattern` with a short verbatim quote from that work (for example: Python "off-by-one in range() bounds" or "mutating a list while iterating", physics "drops units", Japanese "は vs が"). Do not call it for a one-off typo or something the learner merely says is hard. Reuse the existing pattern name from the learner profile when one already matches. Use active recurring weaknesses to choose focused practice and hints.
